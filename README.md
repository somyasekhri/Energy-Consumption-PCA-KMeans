# Energy Consumption Analysis Using PCA and K-Means

An AI/ML project analyzing weekly energy consumption using Exploratory Data Analysis (EDA), Principal Component Analysis (PCA), and K-Means clustering.

🌐 **Live Project Website:** [Click here to view the Energy Consumption Project](https://nandasutaj.github.io/siemen_energy/)

## Key Results
- Dataset containing 321 energy-consumption series and 156 weekly values.
- PCA explains approximately 99.9% of the variance using two components.
- K-Means clustering performed with K = 3.
- Silhouette score: 0.957, with results influenced by extreme outliers.

## Project Files
- `simens_projectipynb.ipynb` — Jupyter Notebook containing the analysis.
- `Siemens_Energy_Clustering Dataset.csv` — Dataset.
